# Small Jev paper (draft)

`main.tex` + `references.bib` + `generated/*.tex`, same layout as the other Morality Lab papers
(article class, booktabs, pgfplots with groupplots). `main.pdf` is the current build.

Build with MiKTeX (installed per-user on this PC; missing packages install on first use):

```powershell
$tex = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64"
cd paper
& $tex\pdflatex main; & $tex\bibtex main; & $tex\pdflatex main; & $tex\pdflatex main
```

On Overleaf, upload `main.tex`, `references.bib` and the `generated/` folder.

Text marked `\pending{...}` (red) is a result still running in the job queues; nothing in red is a
claim. Every number outside those markers comes from a run record:

| Section | Source |
|---------|--------|
| Readouts, post-training | `notes/005-milestone-2-log.md`, `notes/006-milestone-3-log.md` |
| Untrained recurrence | `notes/005`, `results/sweeps/*`, `results/latency/20261001T140802Z_choice.json` |
| Benchmark design | `docs/xbench/SPEC.md` (registered at c457b35), `notes/xbench-log.md` |
| Compactification, control | `reports/xbench/*.md`, generated by `scripts/xbench_report.py` from `results/xbench` |
| Tables 2-4, Figure 2 | `generated/*.tex`, written by `scripts/xbench_paper.py` from `results/xbench` (registered arms only) |

To refresh the benchmark sections after the queues finish: `python scripts/xbench_report.py` and
`python scripts/xbench_paper.py` (tables and the Pareto figure update themselves), then replace the
prose pending markers. Authorship and acknowledgements are left to the
author.
